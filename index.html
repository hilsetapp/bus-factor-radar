DATA BOUNDARY BEFORE YOU SCAN

Your file stays here.

Parsing happens in this tab. When you press Scan, the app sends package names to npm Registry, PyPI, or the Go module proxy to look up public metadata. If a package points to GitHub, public repository and recent commit metadata may be requested from api.github.com.

No manifest content, source code, tokens, or credentials are uploaded. Public services see ordinary requests from your browser. GitHub's unauthenticated REST API is rate-limited per originating IP; all public services apply their own rate limits and privacy policies.
